# Balun

Monorepo containing a Nuxt 4 frontend and a Sanity Studio CMS. Headless Shopify integration.

## Structure

```
balun/
├── nuxt/     # Nuxt 4 frontend
└── sanity/   # Sanity Studio
```

## Getting started

**Sanity Studio**

```bash
cd sanity
npm install
npm run dev
```

**Nuxt**

```bash
cd nuxt
npm install
npm run dev
```
